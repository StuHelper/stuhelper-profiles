# StuHelper Profiles

公开昵称模块，按 issuer 与 subject 保留用户归属。首次登录可以从已验证的 SSO 昵称建立初始资料，之后由本人按修订号修改。后续登录不会覆盖本人修改。

模块只保存公开昵称、修订、幂等结果和必要事件，不保存登录令牌、实名材料、手机号或学校资格。课程与导师评价通过公开接口读取署名昵称。

PostgreSQL 的 profiles schema 由独立迁移身份建立。运行身份只获得该 schema 的业务表权限，不能执行 DDL 或访问其他模块的数据。重复请求返回原结果，同键不同内容及旧修订拒绝写入。

执行 `make check` 验证。数据库测试使用 STUHELPER_PROFILES_TEST_DSN 指定的独立测试数据库。头像、简介、公开主页和注销编排仍按个人中心规格实施。
